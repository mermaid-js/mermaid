Mermaid 图表可视化微调主控制器。

在不修改 Mermaid 核心源码的前提下，通过对 Mermaid 渲染后的 SVG DOM
做二次增强，实现节点拖拽、位置持久化、撤销/重做等功能。

## Example

```typescript
const editor = new MermaidDragEditor({
  svgElement: document.querySelector('#mermaid-0'),
  storageKey: 'my-diagram',
});
await editor.enable();
```
