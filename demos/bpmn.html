BPMN (AI-first) — demo

1. Simple flow

bpmn LR
  start s1 "Start"
  task:user t1 "Review order"
  task:service t2 "Charge card"
  end e1 "Done"
  s1 --> t1 --> t2 --> e1

2. Gateways & conditions

bpmn LR
  start s1 "Order received"
  task:user t1 "Review order"
  xor g1 "Approved?"
  task:service t2 "Charge card"
  end e1 "Shipped"
  end e2 "Rejected"
  s1 --> t1 --> g1
  g1 -- "approved" --> t2 --> e1
  g1 -->|default| e2

3. Pools, lanes & message flow

bpmn LR
  pool "Customer"
    task:user c1 "Place order"
  pool "Supplier"
    lane "Sales"
      start message s1 "Order received"
      xor g1 "In stock?"
    lane "Warehouse"
      task:service t1 "Pick items"
      end e1 "Shipped"
      end e2 "Backordered"
  s1 --> g1
  g1 -- "yes" --> t1 --> e1
  g1 -->|default| e2
  c1 ==> s1

4. Intermediate events (message, timer) & parallel gateway

bpmn LR
  start message s1 "Request received"
  task:user t1 "Assess request"
  intermediate timer i1 "Wait 2 days"
  and g1
  task:service t2 "Notify"
  task:script t3 "Archive"
  end e1 "Closed"
  s1 --> t1 --> i1 --> g1
  g1 --> t2 --> e1
  g1 --> t3 --> e1
