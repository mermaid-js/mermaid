ELK Stress-Minimization Layout

What is Stress-Minimization Layout?

Stress-minimization is an optimization-based layout algorithm that arranges nodes to minimize a global stress metric, which measures the discrepancy between ideal and actual distances. This approach tends to produce more compact, aesthetically pleasing layouts with fewer edge crossings and more natural grouping.
Key Features:
  • Optimization-based: Iteratively minimizes layout stress metric
  • Compact: Creates more condensed layouts than force-directed
  • Organic flow: Produces naturally flowing, intuitive diagrams
  • Edge crossing reduction: Minimizes visual clutter from overlapping edges
  • Configurable precision: Control iteration limits and convergence threshold

Configuration Example

Algorithm: elk.stress
stressDesiredEdgeLength: Target length for edges (optional)
stressIterationLimit: Maximum iterations for optimization (optional)
stressEpsilon: Convergence threshold (optional)

Stress-minimization is particularly effective for documentation and presentations where visual clarity and aesthetic appeal are priorities.

Example 1: Business Process Flow

Stress-minimization creates compact, easy-to-follow layouts perfect for documentation and process diagrams. Notice how the layout naturally groups related activities and minimizes edge crossings. 

flowchart-elk TD
  Start([Start]) --> Intake[Intake]
  Intake --> Validate{Validate}
  Validate -->|Invalid| Reject[Reject]
  Validate -->|Valid| Process[Process]
  Process --> Review{Review}
  Review -->|Need Revision| Revise[Revise]
  Revise --> Process
  Review -->|Approved| Finalize[Finalize]
  Reject --> Notify[Notify User]
  Finalize --> Archive[Archive]
  Notify --> End([End])
  Archive --> End
