ELK Layout Algorithm Comparison

Force-Directed vs Stress-Minimization Layouts

Below is the same graph structure rendered with two different ELK layout algorithms. The graph consists of moderately connected nodes that represent a typical workflow or system architecture.

Algorithm Overview:

  • elk.force (left): Physics-based layout that models nodes as repelling particles and edges as springs. Tends to produce well-separated, visually balanced layouts with nodes spread across the canvas. Better for detecting clusters and relationships.
  • elk.stress (right): Optimization-based layout that minimizes a global stress metric to produce organic, naturally flowing diagrams. Often creates more compact layouts with intuitive grouping. Better for aesthetically pleasing, less cluttered presentations.

Compare the two layouts to see how the algorithm choice affects the visual representation of the same data.

Force-Directed Layout

Algorithm: elk.force with FRUCHTERMAN_REINGOLD model
Characteristics: Physics-based, well-distributed, highly separated nodes
Best for: Showing node relationships and network topology
