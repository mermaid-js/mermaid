Component diagram demos

1. Online shop overview

An actor, components with stereotypes, provided and required interfaces drawn as a ball-and-socket assembly, a port, a package, a dependency and a note. 

component-beta
direction LR
title Online shop
actor Customer
component Web["Web shop"]
component Orders["Order service"] <<service>>
interface IShop["Shop UI"]
interface IOrders["Orders API"]
interface IPay

package Backend {
  component Payments {
    port api
  }
  component Ledger
}

Web --() IShop
Customer --( IShop
Orders --() IOrders
Web --( IOrders
Payments.api --() IPay
Orders --( IPay
Payments ..> Ledger : writes to
note for Orders "handles checkout"

2. Ball-and-socket assembly

The smallest assembly: one component provides an interface (--()), another requires it (--(). Top-to-bottom layout puts the interface name on the side. 

component-beta
direction TB
component Client
component Server
interface HTTP
Server --() HTTP
Client --( HTTP

3. One provider, several consumers

Several components require the same interface. Each one gets its own socket around the shared ball. 

component-beta
direction LR
component Auth["Auth service"] <<service>>
interface IAuth["Auth API"]
component Web["Web app"]
component Mobile["Mobile app"]
component Admin["Admin console"]
Auth --() IAuth
Web --( IAuth
Mobile --( IAuth
Admin --( IAuth

4. Ports and nested components

A component with ports and inner parts. Ports sit on the component border, and an edge can start or end at a port with Component.port. 

component-beta
direction LR
component Gateway["API gateway"] {
  port http
  port grpc
  component Router
  component RateLimiter["Rate limiter"]
}
component Catalog["Catalog service"]
component Search["Search service"]
interface REST["REST API"]
interface RPC["gRPC API"]
Gateway.http --() REST
Gateway.grpc --() RPC
Catalog --( RPC
Search --( RPC
Router --> RateLimiter : checks

5. Layered architecture with packages

Packages group components into layers. Dependencies (..>) point down the stack, and nested packages show sub-systems. 

component-beta
direction TB
package Presentation {
  component UI["Web UI"]
  component CLI
}
package Application {
  component OrderService["Order service"]
  component BillingService["Billing service"]
}
package Infrastructure {
  package Persistence {
    component Repo["Order repository"]
    component DB["Database"] <<database>>
  }
  component Queue["Message queue"]
}
UI ..> OrderService : uses
CLI ..> OrderService : uses
OrderService ..> BillingService : uses
OrderService ..> Repo : stores via
Repo ..> DB
BillingService ..> Queue : publishes

6. Actors and external systems

Actors are people or systems outside the diagram's scope. They can use an interface like any component does, or link to a component directly. 

component-beta
direction LR
actor Customer
actor Support["Support agent"] <<staff>>
actor Bank["Bank"] <<external>>
component Portal["Customer portal"]
component Tickets["Ticket system"]
component Payments["Payment service"]
interface IPortal["Portal UI"]
interface IBank["Bank API"]
Portal --() IPortal
Customer --( IPortal
Support --> Tickets : works on
Portal --> Tickets : opens
Bank --() IBank
Payments --( IBank
Portal --> Payments : pays with

7. Relationship kinds

Every connector: provided interface --(), required interface --(, dependency ..>, association --> and a plain link --, each with an optional : label. 

component-beta
direction LR
component A
component B
component C
component D
component E
interface I
A --() I : provides
B --( I : requires
B ..> C : depends on
C --> D : calls
D -- E : linked to

8. Styling and notes

classDef and class style several elements at once, style styles one element, and note for attaches a note. 

component-beta
direction LR
component Legacy["Legacy billing"] <<deprecated>>
component Billing["Billing v2"]
component Reports
interface IInvoices["Invoices API"]
Billing --() IInvoices
Reports --( IInvoices
Legacy ..> Billing : migrating to
classDef old fill:#fde2e2,stroke:#c0392b,stroke-dasharray: 4 3
classDef fresh fill:#e2f7e2,stroke:#27ae60
class Legacy old
class Billing fresh
style Reports stroke:#2980b9,stroke-width:3px
note for Legacy "switched off after Q3"
