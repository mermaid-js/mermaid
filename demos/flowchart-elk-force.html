What is Force-Directed Layout?

      

        Force-directed layout simulates a physical system where nodes repel each other (like magnets
        with the same polarity) while edges act like springs pulling connected nodes together. This
        creates naturally distributed, balanced layouts that are excellent for visualizing network
        topology.
      

      

        Key Features:
        
    
          
  • 
            Physics-based: Uses repulsive and attractive forces to achieve
            equilibrium
          
    • 
          
  • Well-distributed: Spreads nodes evenly across the canvas
    • 
          
  • 
            Relationship visibility: Makes it easy to see node clusters and
            connections
          
    • 
          
  • 
            Configurable: Adjust iterations, repulsion, and temperature for
            fine-tuning
          
    • 
        

      

    


    

      
Configuration Example

      

        Algorithm: elk.force

        forceModel: FRUCHTERMAN_REINGOLD or EADES

        forceIterations: Number of refinement iterations (default: 300)

        forceRepulsion: Strength of node repulsion (default: 5.0)

        forceTemperature: Cooling schedule (default: 0.001)
      

      

        Increase iterations and temperature for more refined layouts on complex graphs. Higher
        repulsion spreads nodes further apart.
