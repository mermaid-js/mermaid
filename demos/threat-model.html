Working with this PoC

Add elements by their existing node IDs. Give annotated edges explicit IDs, e.g. API query@--> DB. A subgraph becomes a trust boundary when annotated as kind: boundary.

Record candidate threats, review severity and decisions, then add mitigation tasks and evidence. Set model state explicitly; rendering is not security approval. No AI service is called and no data is uploaded.

Evidence is a reference, not proof verified by Mermaid. Deployment warnings are advisory.
