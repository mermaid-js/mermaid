Ditaa Diagram Demo

This page demonstrates the ditaa diagram type in Mermaid. Ditaa converts ASCII art into polished box-and-arrow diagrams.

1 — Single Box

ditaa
+----------+
|          |
|  Client  |
|          |
+----------+

2 — Two Boxes with Arrow

ditaa
+----------+         +------------+
|          |         |            |
|  Client  | ------> |  Webserver |
|          |         |            |
+----------+         +------------+

3 — Bidirectional Arrow

ditaa
+----------+         +------------+
|          |  https  |            |
|  Client  | <-----> |  Webserver |
|          |         |            |
+----------+         +------------+

4 — Full Architecture Example (from the feature request)

ditaa
+----------+         +------------+         +-----------+
|          |  https  |            |  http   |   ocis    |
|  Client  | <-----> |  Webserver | <-----> |   proxy   |
|          |         |            |         |  service  |
+----------+         +------------+         +-----------+
                     ^                      ^
                     |                      |
                     |                      |
                 Termination             Unsecured
