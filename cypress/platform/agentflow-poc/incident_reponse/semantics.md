## graphs

For agents and tools, we need an instansiation concept. So if I use an agent in multiple places, I define everything about the agent in one place and then refer to it by setting the agent ID in the agent shape. This means that all the descriptions and everything around the agent can be in the one place where you define the agent, but the use is in the SHAPES.md. Same thing goes for tools. That means when we set up the data for layout, we pick the title from the tool, not the ID.
