Grid-attached layout

grid-decomposed with the decomposition put back together. The core is the same grid-like drawing — same solve, same alignments, same straight centre-to-centre edges — and every tree HOLA's leaf peeling removed is hung back onto the core node it came from. Where it hangs is HOLA's answer (guide §17): largest tree first, into the angular wedge of a face at its root, cardinal direction before ordinal, external face before internal.

The one liberty taken with the core is enlargement. HOLA makes room for a tree by expanding the face around it, which moves core nodes and would destroy the alignments that make a grid-like drawing grid-like. So instead every core node is moved away from the core's centre by a common factor: every core edge gets longer and nothing else changes — the same picture, more room. That factor is raised only as far as it pays for itself against the dead stubs it saves.

A wide fan — one node, many connectors

Every connector leaving one side of one node gets its own attachment point, and the fan's turns are nested into a comb so each run sits on its own line. Without either, all eight arrive as one thick stem and one thick bar and no reader can tell which arrow goes where. The rank gap is widened to hold the comb rather than being fixed, so a chain still gets a tight gap and only a fan pays for the room it needs.
