feat(layout): add the `grid-attached` layout algorithm. It is `grid-decomposed` with the decomposition put back together: HOLA's undirected leaf peeling splits each component into a core and its trees, the core is laid out by `grid-like`, and every peeled tree is then drawn by HOLA's symmetric tree layout and hung back onto the core node it came from. Where it hangs is HOLA's own face search — largest tree first, into the angular wedge of a face at its root, cardinal direction before ordinal, external face before internal — read off the straight-line core drawing. Nothing is duplicated and nothing is packed beside anything else: one connected diagram in, one connected diagram out. The only change made to the core drawing is a uniform enlargement of its edges, which preserves every grid-like alignment and is raised only as far as it pays for itself against the dead connector stubs it saves. Select it with `layout: 'grid-attached'`. Tree connectors are re-derived from the final positions with HOLA's own rank connector and routed once per component, so the several ways two connectors can end up drawn as one line are all handled: every connector using one side of one node gets its own attachment point (whichever tree it belongs to), and a parent's fan turns in a nested comb inside a rank gap widened to hold it. The core's edges are routed orthogonally by HOLA's own router rather than drawn as grid-like's straight centre-to-centre lines: node positions are untouched, so every alignment and the grid structure survive, but a pair the alignment pass did not align no longer gets a diagonal that is free to pass through a third node's box. Routing runs on each rung of the enlargement ladder, so the faces, the obstacles a tree must clear and the corridor its connector runs through all see the geometry that is actually drawn. Because grid-like's beautification is greedy and never undone, the drawing it produces for a small core is unstable — a four-cycle came out four different ways under sub-pixel changes to the derived grid spacing, only one of them the obvious rectangle. grid-like is therefore asked several times, over the knobs the paper leaves open (whether the flow ordering is imposed, which phase-2 mechanism runs, which cost function ACA ranks alignments with), and the drawing with the fewest edges through nodes, then crossings, then unaligned pairs is kept. `grid-decomposed` is unaffected and keeps drawing its cores exactly as before.
