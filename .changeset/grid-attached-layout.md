feat(layout): add the `grid-attached` layout algorithm. It is `grid-decomposed` with the decomposition put back together: HOLA's undirected leaf peeling splits each component into a core and its trees, the core is drawn by `grid-like` exactly as `grid-decomposed` draws it, and every peeled tree is then drawn by HOLA's symmetric tree layout and hung back onto the core node it came from. Where it hangs is HOLA's own face search — largest tree first, into the angular wedge of a face at its root, cardinal direction before ordinal, external face before internal — read off the straight-line core drawing. Nothing is duplicated and nothing is packed beside anything else: one connected diagram in, one connected diagram out. The only change made to the core drawing is a uniform enlargement of its edges, which preserves every grid-like alignment and is raised only as far as it pays for itself against the dead connector stubs it saves. Select it with `layout: 'grid-attached'`. Tree connectors are re-derived from the final positions with HOLA's own rank connector and routed once per component, so the several ways two connectors can end up drawn as one line are all handled: every connector using one side of one node gets its own attachment point (whichever tree it belongs to), and a parent's fan turns in a nested comb inside a rank gap widened to hold it.
